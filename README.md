# pictalk
Talk is cheap

PicTalk - application de communication par pictogrammes

INSTALLATION (Android)

1. Ouvrir l'adresse dans Chrome sur la tablette, menu ⋮, "Installer l'application".
2. Lancer une fois avec du réseau : ensuite tout fonctionne hors ligne.

MODE ÉDITION : appui long (1 s) sur le bouton ⚙. Dans ce mode, touchez une entrée pour la modifier, une case vide (+) pour en créer une. ⚙ (appui court) ouvre les réglages et la sauvegarde.
SAUVEGARDE : Réglages > Exporter (fichier .json avec les images). À refaire régulièrement.
PICTOGRAMMES ARASAAC : licence CC BY-NC-SA, mention de l'auteur requise.

CODE D'ACCÈS : appui long sur ⚙ -> la première fois, l'application propose de créer un code (4 caractères ou plus)
et affiche un CODE DE SECOURS à noter (il ne sera plus montré). Ensuite, le code est demandé à chaque entrée en mode édition.
Après 5 erreurs : attente de 30 s. Code oublié : "Code oublié ?" puis code de secours. Changer ou retirer le code : ⚙ > Code d'accès...
Le mode édition se referme tout seul après 3 minutes sans toucher l'écran ou quand l'application passe en arrière-plan.
Le code est conservé séparément de la grille : il n'est ni exporté ni modifié par un import de sauvegarde.
Ce code dissuade un enfant de modifier la grille ; ce n'est pas une protection contre quelqu'un qui maîtrise l'outil du navigateur.
