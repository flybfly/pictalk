PicTalk - application de communication par pictogrammes
=======================================================

INSTALLER L'APPLICATION (Android)
1. Ouvrir l'adresse de PicTalk dans Chrome, sur la tablette.
2. Menu ⋮ > "Installer l'application".
3. Lancer l'application une première fois avec du réseau. Ensuite, elle fonctionne aussi sans connexion.


UTILISER L'APPLICATION
- Touchez les cases pour construire la phrase : les mots apparaissent en haut.
- Une case avec une flèche › ouvre une page ; une case à contour pointillé est un dossier qui n'est pas prononcé.
- Chaque mot est prononcé dès que vous le touchez. À la fin, le bouton 🔊 Énoncer lit la phrase entière.
- ⌫ efface le dernier mot. ✕ efface toute la phrase d'un seul toucher (réglable : ⚙ en mode édition > "Effacer avec ✕ : demander une 2e touche", pour éviter les effacements par erreur). ↩ revient à la page précédente. 🏠 retourne à l'accueil.
- La barre du bas (Oui, Non, Stop, Attends, Aide, Toilettes) est toujours visible : une seule touche suffit, la phrase est prononcée tout de suite.


MODIFIER LES CASES (mode édition)
1. Appui long (1 seconde) sur le bouton ⚙. Un cadre jaune en pointillé indique que le mode édition est actif.
2. Touchez une case pour la modifier, ou une case vide (+) pour en créer une. Vous pouvez choisir :
   - le libellé affiché et, si besoin, un texte prononcé différent ;
   - si le mot est prononcé ou non (dossier muet) ;
   - la page liée : aucune, une page existante ou une nouvelle page (autant de niveaux que souhaité) ;
   - la couleur ;
   - l'image : un emoji, une photo ou une image de l'appareil.
3. "Déplacer" échange la case avec une autre. "Supprimer" vide la case.
4. En haut : ✎ renomme la page, 🗑 la supprime.
5. Pour quitter : nouvel appui long sur ⚙. Le mode édition se ferme aussi tout seul après 3 minutes sans toucher l'écran, ou quand l'application passe en arrière-plan.


CODE D'ACCÈS
Le code empêche de modifier la grille par accident.
- À la première entrée en mode édition, l'application propose de créer un code (4 caractères ou plus) et affiche un CODE DE SECOURS. Notez-le et gardez-le à part : il ne sera plus montré.
- Ensuite, le code est demandé à chaque entrée en mode édition. Après 5 erreurs, il faut attendre 30 secondes.
- Code oublié : "Code oublié ?", puis saisir le code de secours et choisir un nouveau code.
- Changer ou retirer le code : ⚙ (appui court, en mode édition) > "Code d'accès...".
- Le code reste sur la tablette : il n'est pas inclus dans les sauvegardes et n'est pas modifié par un import.
Ce code dissuade un enfant de modifier la grille ; il ne protège pas contre quelqu'un qui maîtrise les outils du navigateur.


METTRE À JOUR LES PICTOGRAMMES
Quand de nouveaux pictogrammes sont disponibles (fichier extra-picto.json publié avec l'application) :
1. Connectez la tablette à Internet.
2. Mode édition (appui long sur ⚙, code demandé), puis ⚙ (appui court) > "Mettre à jour les pictogrammes".
3. Confirmez. L'application indique le nombre d'entrées mises à jour.
Ce que fait la mise à jour :
- les emojis et les anciens pictogrammes sont remplacés par les nouveaux, pour les entrées de même nom ;
- vos propres photos sont conservées ;
- les entrées, pages et réglages que vous avez ajoutés ou modifiés ne sont pas touchés.
Si la mise à jour échoue, vérifiez la connexion et réessayez.


CHOISIR LA VOIX
Mode édition > ⚙ (appui court) > "Voix". La liste montre d'abord les voix françaises installées sur la tablette ; la voix choisie dit aussitôt une phrase d'essai.
Une voix française est toujours utilisée par défaut, même si vous n'en choisissez pas. Pour avoir plus de voix, installer des voix dans les réglages de synthèse vocale d'Android.


CHERCHER UN PICTOGRAMME SUR ARASAAC (mode édition)
1. Touchez une case pour la modifier, puis "🔎 Chercher sur ARASAAC". Le site arasaac.org s'ouvre dans un autre onglet, directement sur la recherche du mot : le libellé de la case, ou le mot-clé que vous saisissez à côté du bouton. Le menu ⚙ contient aussi un champ de recherche libre.
2. Choisissez un pictogramme. Deux façons de le ramener dans PicTalk :
   - télécharger l'image sur arasaac.org, revenir à PicTalk et utiliser "📷 Photo / image" ;
   - ou recopier le numéro du pictogramme (visible dans l'adresse de sa fiche) dans "N° ou lien ARASAAC", puis "Importer". Si le téléchargement automatique échoue, utiliser la première méthode.
3. Enregistrer la case.
Si Android ferme PicTalk pendant que vous êtes sur le site, la case en cours de modification peut ne pas être sauvegardée : enregistrez d'abord le libellé, puis reprenez la modification.


ORIENTATION (PAYSAGE UNIQUEMENT)
PicTalk est conçu pour l'écran en paysage. Installée sur la tablette, l'application demande le mode paysage à Android.
Si la tablette est tenue en portrait malgré tout, un message "Tournez la tablette en mode paysage" masque l'écran jusqu'à ce qu'elle soit tournée.
Si l'application était déjà installée avant cette mise à jour, Android peut mettre quelques jours à prendre en compte le nouveau réglage : pour l'appliquer tout de suite, exportez une sauvegarde, désinstallez PicTalk, réinstallez-le, puis importez la sauvegarde.
Pensez aussi à désactiver le verrouillage de la rotation d'Android si l'écran ne tourne pas.

NOUVEAUTÉS DE LA GRILLE (version 3)
- Peur : J'ai > peur > (du noir, de l'orage, d'être seul(e), des monstres, du chien, du docteur, ...). Même chose pour un tiers : Il / Elle / On / Tu / Ça > il > a > peur > ...
- Le temps : Raconter > Le temps, ou Il / Elle / On / Tu / Ça > Il (le temps). Une touche : Il pleut, Il neige, Il fait froid... ; "Il fait..." et "Il y a..." ouvrent des listes pour composer la phrase.
- Problèmes (bruit, lumière, monde) : Aider / Réparer > Problèmes.
- C'est > trop > bruyant, fort, chaud, froid, sombre.
Mise à jour d'une grille existante : au premier lancement (ou après un import), PicTalk ajoute ces pages sans effacer vos modifications : vos entrées, photos et suppressions sont conservées.

SAUVEGARDER ET RESTAURER
- ⚙ > "Exporter la sauvegarde" crée un fichier pictalk-sauvegarde-DATE.json (grille, images, réglages). À refaire régulièrement, et toujours avant d'effacer les données de Chrome.
- ⚙ > "Importer" restaure un fichier de sauvegarde. ATTENTION : l'import REMPLACE tout le contenu de l'application.
- ⚙ > "Réinitialiser" remet la grille d'origine : vos modifications sont perdues.


RÉGLAGES (⚙ en mode édition)
- Retour à l'accueil après une phrase.
- Effacer avec ✕ : une seule touche (par défaut) ou deux touches (la première demande confirmation et expire après 2 secondes).
- Genre des accords (Garçon / Fille) : fatigué / fatiguée, heureux / heureuse, etc.
- Voix et vitesse de la voix (voir plus bas). Les voix disponibles dépendent de celles installées sur Android.


EN CAS DE PROBLÈME
- Pas de son :
  1. Régler le volume MULTIMÉDIA d'Android (le volume des sonneries est différent) et vérifier que le mode silencieux ou "Ne pas déranger" n'est pas actif.
  2. Dans l'application : ⚙ en mode édition > "Tester la voix". Un message peut indiquer qu'aucune voix française n'est installée.
  3. Réglages d'Android > Accessibilité > Synthèse vocale (ou Langue et saisie > Synthèse vocale) :
     - moteur préféré : "Speech Services by Google" (à installer depuis le Play Store si absent) ;
     - ouvrir ses paramètres > Installer les données vocales > Français (France), puis télécharger la voix ;
     - appuyer sur "Écouter un exemple" : si rien ne sort ici, le problème vient d'Android et non de PicTalk.
  4. Fermer complètement l'application et la rouvrir.
- Une modification n'apparaît pas : fermer complètement l'application, puis la rouvrir avec du réseau.
- Les données (grille, photos, réglages) sont enregistrées sur la tablette, dans Chrome. Les effacer supprime tout : exportez une sauvegarde avant.
